# IMAGE-PRESS

Offline image optimization app built with Next.js.

## What it does

- Compress JPG, PNG, WebP, AVIF, GIF, BMP, and ICO files
- Resize images by percentage
- Choose output format
- Process batches in the browser
- Save directly from the queue

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000/image` if you keep this inside the existing workspace setup, or `/` if this repo is used standalone.

## Build

```bash
npm run build
```
